WIDGET FOCUS STATES:
────────────────────
When a widget is focused, its border changes to double-line (══) or bold,
and the status bar shows which pane is active.

Example - Teams pane focused:
╔══════════════════╗
║ >> TEAMS         ║  ← ">>" marker + double border indicates focus
╠══════════════════╣
║  ▼ Engineering   ║  ← highlighted item shown with inverse/bold
║ ►  # general  3  ║  ← "►" shows cursor position within list

┌────────────────────────────────────────┐
│ Type a message...                    │ │  ← cursor visible
